## `>` research.spotlight
 
<div align="center">
<h3>🧠 AMMFF — Adaptive Multi-Modal Fusion Framework</h3>
</div>
> A deep learning architecture that fuses **chest X-ray imaging** with **18 structured clinical features** to predict the **14 CheXpert pathology labels** — and keeps performing when a modality goes missing at inference time.
 
<table>
  <tr><td width="22%"><b>Architecture</b></td><td>Adaptive Fusion Weighting (AFW) + Missing-Modality Reconstruction (MMR)</td></tr>
  <tr><td><b>Data</b></td><td>MIMIC-CXR-JPG (30,678 images) · CheXpert</td></tr>
  <tr><td><b>Stack</b></td><td>PyTorch · Google Colab / Kaggle GPUs · FastAPI + Angular + Docker deployment platform</td></tr>
  <tr><td><b>Baselines</b></td><td>Benchmarked against <b>DrFuse</b> and <b>MedFuse</b></td></tr>
  <tr><td><b>Status</b></td><td>7 model variants trained · best AUC <b>0.7428</b> · thesis in IEEE format</td></tr>
</table>
